# docs/

Tài liệu kỹ thuật của dự án: kiến trúc, quy ước, hướng dẫn setup môi trường,
API reference, quyết định thiết kế (ADR)...

Gợi ý cấu trúc:
- `docs/architecture.md` — tổng quan kiến trúc Modular Monolith, luồng request qua Controller → Service → Repository.
- `docs/routing.md` — quy ước 4 loại route (web/manager/superadmin/api).
- `docs/theme.md` — bảng màu, token CSS, quy tắc border.
- `docs/modules/{TenModule}.md` — tài liệu riêng từng module khi cần.
